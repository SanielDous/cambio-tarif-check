# Tarif-Check Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A static single-page app in which a cambio customer drops their trip export and sees, per
month, what they paid and what every other tariff would have cost.

**Architecture:** Pure TypeScript domain modules (`pricing`, `import`, `analysis`) without React hold
all rules and almost all tests. Jotai atoms hold imported trips and settings and derive the analysis.
React features render import and result. Nothing is sent or stored.

**Tech Stack:** pnpm, Node ≥ 22, React 19, Vite 6, TypeScript strict, TanStack Router (hash history),
Jotai, Tailwind CSS v4, shadcn/ui, lucide-react, Recharts, i18next, Papa Parse, read-excel-file,
Vitest, Testing Library, Playwright, ESLint 9, Prettier, semantic-release.

**Spec:** `docs/design/2026-11-23-tarif-check-design.md` (sections 1–6; section 2a and delivery
steps 2 and 3 are **not** part of this plan). Domain facts: `docs/research/cambio-pricing.md`.

## Global Constraints

- Code, comments, docs, commit messages in English. Issues and PR descriptions in German.
- UI texts only via i18next keys; `de` is the default and fallback language, `en` must be complete.
  A test fails if the key sets of `de` and `en` differ.
- No network requests at runtime, no persistence of trips (no localStorage/IndexedDB/cookies).
- Never commit `Fahrten_*.csv`, `Fahrten_*.xlsx` or anything from `private/`. Never put personal
  data (names, licence plates, stations, comments, invoice numbers) into code, tests or fixtures.
- Money is handled in **integer cents** once rounded; unrounded intermediate values are fractional
  cents as `number`. Never use floats in euros.
- Times are naive local minutes (`LocalMinute` = minutes since 1970-01-01 00:00 local wall-clock).
  Never construct a `Date` from export times in local-time-zone mode; results must be identical in
  any browser time zone.
- TypeScript: `strict`, `noUncheckedIndexedAccess`, `noFallthroughCasesInSwitch`, alias `@/*` →
  `src/*`. File names kebab-case. Tests next to the source as `*.test.ts(x)`.
- Prettier: semicolons, double quotes, trailing commas `all`, print width 100, tab width 2.
- Vite `base` is `/cambio-tarif-check/`.
- Conventional Commits. One branch and one pull request per task, PR description in German with
  the sections "Was", "Warum", "Prüfung". Merge when CI is green.
- The page states that it is an unofficial tool, not affiliated with cambio.
- Do not add a `.npmrc`; the registry is configured per machine. CI uses the default registry.

## Review Focus

1. **Changed export layout** (columns renamed, reordered, extra columns, a title line above the
   header): the standard case must still import without a dialog when names are close; otherwise
   the mapping dialog appears – never a crash or a silently wrong column. → Task 6.
2. **XLSX cell types** (dates as serials/`Date`, numbers as numbers, text as text) must yield exactly
   the same trips as the CSV of the same export. → Task 6.
3. **Unknown values** (tariff not in the price data such as `PROFI`, vehicle class without a known
   price class, trip before 2024-05-02, rows without amounts): the row is listed with a reason and
   excluded; everything else is still evaluated. → Tasks 5, 6.
4. **Degenerate periods** (one trip, one month, months without trips, trip spanning a month or year
   boundary): all figures stay defined, no `NaN`, no empty matrix. → Task 7.
5. **Wrong input** (empty file, PDF, 5 MB of unrelated CSV, browser in another time zone): a clear
   message, the page stays usable; amounts do not depend on the time zone. → Tasks 6, 8.

```ts
/** Capped time cost in fractional cents for a booking [start, end), caps anchored at `start`. */
export function timeCost(start: LocalMinute, end: LocalMinute, tariff: TariffId, cls: PriceClass, data: PriceData): number;
```

Rules (all from the research document, "Observed in the calculator"):

- Km: first 100 km at `kmTier1 + surcharge`, the rest at `kmTier2 + surcharge`.

### Task 5: Booking reconstruction, verified against real trips

**Files:** `src/domain/analysis/reconstruct-booking.ts`, `trip-cost.ts`, tests,
`src/domain/analysis/real-trips.test.ts`. Also defines `Trip` in `src/domain/import/fields.ts`
if Task 6 has not created it yet (same definition, see Task 6).

**Interfaces – Consumes:** Tasks 3, 4, `Trip` (Task 6). **Produces:**

```ts
export type ReconstructionKind =
  | "verified" | "verified-rounding" | "estimated" | "manual"
  | "cancelled" | "unused" | "not-reproducible";
export interface Reconstruction {
  kind: ReconstructionKind;
  chargedUntil: LocalMinute;   // return rounded up to the quarter hour
  bookedEnd: LocalMinute;
  share: 1 | 0.5;              // 0.5 only for "cancelled"
  surchargeCents: number;      // from the table, or derived from the billed km amount
  surchargeDerived: boolean;
  timeDeviation: number;       // model − billed, cents, in the actual tariff
  kmDeviation: number;
}
export function bookingTimeCost(start: LocalMinute, chargedUntil: LocalMinute, bookedEnd: LocalMinute,
  share: 1 | 0.5, tariff: TariffId, cls: PriceClass, data: PriceData): number; // integer cents
export function reconstructBooking(trip: Trip, data: PriceData, manualBookedEnd?: LocalMinute): Reconstruction;
export function tripCostInTariff(trip: Trip, r: Reconstruction, tariff: TariffId, data: PriceData):
  { time: number; km: number } | null; // null if the tariff has no price for the class
```

Rules:
- `bookingTimeCost` = `roundHalfUp(share × timeCost(start, chargedUntil))` +
  `roundHalfUp(0.5 × (timeCost(start, bookedEnd) − timeCost(start, chargedUntil)))`.
- Km check first: expected km cost with the table surcharge; if it differs, try surcharges 0–10 ct
  and take the one that matches exactly (`surchargeDerived: true`); if none, `kmDeviation ≠ 0`.
- `km === 0`: compare billed time with `timeCost(start, chargedUntil)` rounded: within 1 cent of
  100 % → `unused` (share 1, bookedEnd = chargedUntil); within 1 cent of 50 % → `cancelled`
  (share 0.5, bookedEnd = chargedUntil); otherwise continue as a normal trip.
- Search `bookedEnd` from `chargedUntil` in 15-minute steps up to 30 days after `start`. Collect
  exact matches and 1-cent matches of the billed time amount. Exact match(es): take the earliest;
  `verified` if it is the only exact match within the next 24 hours of candidates, else
  `estimated`. Only 1-cent matches: earliest, `verified-rounding`. None: `not-reproducible` with
  `bookedEnd = chargedUntil`.
- `manualBookedEnd` (must be ≥ `chargedUntil` and on a quarter hour, else ignored): kind `manual`.
- A trip whose end is before `data.validFrom` or whose tariff/class has no price is not
  reconstructed here; Task 6 excludes such rows.

Steps:

- [ ] Unit tests on synthetic trips for every kind, e.g.: start 17:15, end 19:21, AKTIV S,
  billed time 498 → `verified-rounding` or `verified` with `bookedEnd` 19:45 (assert the booked
  end, and that the deviation is within 1); BASIS L Tuesday 18:00–20:23, 13 km, billed 1967 time
  and 546 km with table surcharge 3 → `verified`, `bookedEnd` 21:00, `kmDeviation` 0; a 0 km row
  AKTIV L 13:00–20:00 billed 1785 → `cancelled`; AKTIV XL 09:00–18:00 billed 5508 → `unused`;
  AKTIV S 15:00–20:00 billed 1141 → `not-reproducible`, `timeDeviation` −91.
- [ ] `tripCostInTariff` test: a `cancelled` trip costs 50 % of the other tariff's time cost; a
  verified early return keeps `chargedUntil` and `bookedEnd` in the other tariff.
- [ ] `real-trips.test.ts` over both CSV fixtures (parse them with a small local helper if Task 6
  is not merged yet): **all 85 km amounts exact with the table surcharge**; every trip except one

- [ ] If the long trip (8 days, 1495 km) or night trips do not reach `|timeDeviation| ≤ 1` under

### Task 6: Import

**Files:** `src/domain/import/fields.ts`, `read-table.ts`, `detect-columns.ts`,
`normalize-rows.ts`, `dedupe.ts` and tests.

**Interfaces – Consumes:** `parseLocal`, `PRICE_DATA` (Task 3). **Produces:**

```ts
export type FieldId = "city" | "vehicleClass" | "start" | "end" | "km" | "billedTime" | "billedKm"
  | "tariff" | "driver" | "tripStart" | "tripEnd" | "billedTotal" | "status" | "invoiceDate";
export const REQUIRED_FIELDS: FieldId[]; // the first eight
export const FIELD_ALIASES: Record<FieldId, string[]>; // first alias = today's header
export interface Trip {
  id: string;                 // stable hash of start, end, vehicleClass, km, billedTime, billedKm
  city: string; vehicleClass: string; priceClass: PriceClass;
  start: LocalMinute; end: LocalMinute; km: number;
  billedTime: number; billedKm: number;   // integer cents
  tariff: TariffId; driver?: string; status?: string;
}
export interface RawTable { fileName: string; headers: string[]; rows: unknown[][] }
export type ColumnMapping = Partial<Record<FieldId, number>>;
export interface Detection { mapping: ColumnMapping; missing: FieldId[]; ambiguous: FieldId[] }
export type RowProblem = { fileName: string; rowNumber: number; reason:
  "invalid-date" | "invalid-number" | "end-before-start" | "unknown-tariff" | "unknown-class"
  | "before-price-data" | "not-billed"; detail?: string };
export async function readTable(file: File): Promise<RawTable>;   // throws ImportError
export class ImportError extends Error { code: "empty" | "unsupported" | "unreadable" | "too-large" }
export function detectColumns(headers: string[]): Detection;
export function normalizeRows(table: RawTable, mapping: ColumnMapping, data: PriceData):
  { trips: Trip[]; problems: RowProblem[] };
export function dedupeTrips(trips: Trip[]): { trips: Trip[]; duplicates: number };
```

Rules:
- Today's headers (first aliases): `Stadt`, `Wagenklasse`, `Buchungsbeginn`, `Buchungsende`,
  `Kilometer`, `Betrag Zeit`, `Betrag Kilometer`, `Tarif`, `fahrende Person`, `Fahrtbeginn`,
  `Fahrtende`, `Betrag Gesamt`, `Verarbeitungsstatus`, `Rechnungsdatum`. Add sensible German and
  English variants as further aliases.
- Header normalisation: lower-case, trim, strip diacritics and everything that is not a letter or
  digit. Match exactly on normalised aliases first; then by similarity (normalised Levenshtein
  distance ≤ 0.25 of the longer string). A field is `ambiguous` if two columns qualify equally;
  a column is used for one field only.
- The header row is the first of the first 10 rows that contains at least 5 recognised fields.
- CSV: Papa Parse, delimiter auto-detected, BOM stripped, UTF-8; if the text contains U+FFFD,
  re-decode as windows-1252.
- XLSX: read-excel-file, first sheet, dynamically imported. `Date` cells are converted to local
  minutes from their **UTC** components; numeric cells are used as numbers.
- Numbers as text accept decimal comma and thousands point. Amounts → cents via rounding.
- Price class = first whitespace-separated token of the vehicle class if it is one of the five.
- Tariff = trimmed upper-case value if it is a `TariffId`.
- `not-billed`: time and km amount both empty. `before-price-data`: end before `validFrom`.

### Task 7: Monthly analysis

**Interfaces – Consumes:** Tasks 3, 5, 6. **Produces:**

```ts
export interface Settings { additionalDrivers: number; under26: boolean;
  period: { from: string; to: string } | null;            // month keys, inclusive
  manualBookedEnds: Record<string, LocalMinute> }          // by trip id
export interface TripResult { trip: Trip; reconstruction: Reconstruction; month: string;
  costs: Partial<Record<TariffId, { time: number; km: number }>> }
export interface MonthRow { month: string; tripIds: string[];
  actualTariff: TariffId; actualTariffMixed: boolean; switched: boolean;
  actualCost: number;                                      // billed + fees + switching fee
  costs: Partial<Record<TariffId, number>>;                // model incl. fees
  cheapest: TariffId; incomplete: boolean }
export interface Analysis {
  tariffs: TariffId[];                                     // compared, ordered by monthly fee
  trips: TripResult[]; months: MonthRow[];
  totals: Partial<Record<TariffId, number>>; actualTotal: number;
  bestSingle: { tariff: TariffId; total: number; saving: number };
  optimalPath: { tariffs: TariffId[]; total: number; switches: number };
  recomputationDeviation: number;                          // Σ model in actual tariff − Σ billed

  surchargeDerivedTrips: number;
}
export function analyze(trips: Trip[], settings: Settings, data: PriceData): Analysis | null; // null: no trips
export function comparedTariffs(trips: Trip[], settings: Settings, data: PriceData): TariffId[];
```
